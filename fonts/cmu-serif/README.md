# Local Computer Modern Unicode type

These are unmodified CMU Serif OpenType fonts from the CTAN `cm-unicode` package, licensed under the included SIL Open Font License. They are retained as **unused legacy assets** from the Lesson 2 edition. The current website follows the teacher's later request to use Arial for ordinary content; these files no longer select the website font. Their original redistribution notices remain alongside them.

Primary sources checked 16 October 2026:

- [3Blue1Brown's own video configuration](https://github.com/3b1b/videos/blob/master/custom_config.yml) explicitly sets text font to `CMU Serif`, TeX template to `default` and camera background to black.
- [ManimGL default configuration](https://github.com/3b1b/manim/blob/master/manimlib/default_config.yml) links to that personal configuration. Its separate generic default uses Consolas. The former site edition followed the video project's CMU Serif choice; the current edition uses Arial for ordinary content.
- [CTAN Computer Modern Unicode package](https://ctan.org/pkg/cm-unicode), downloaded from `https://mirrors.ctan.org/fonts/cm-unicode.zip`.

Original font filenames: `cmunrm.otf`, `cmunbx.otf`, `cmunti.otf`, `cmunbi.otf`. Only the asset filenames have been made descriptive; font binaries are unchanged. SVG teaching diagrams and ordinary HTML content now use Arial. Mathematical expressions continue to use the locally bundled KaTeX renderer and the specialised glyph fonts required by its formula layout.

This is an original physics resource with an independently authored visual teaching approach. It is not affiliated with or endorsed by 3Blue1Brown.
